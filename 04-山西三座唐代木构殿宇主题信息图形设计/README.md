# 唐构三殿 · 山西木构比较图谱

以佛光寺东大殿的拆层轴测为入口，对照南禅寺大殿、广仁王庙正殿和佛光寺东大殿的纪年、开间、屋顶与外檐柱头铺作。下方将南禅寺和佛光寺的柱高统一为 1.00，对比铺作和屋架高度。广仁王庙保留在前两项对照中，比例图标明单独的资料范围。
