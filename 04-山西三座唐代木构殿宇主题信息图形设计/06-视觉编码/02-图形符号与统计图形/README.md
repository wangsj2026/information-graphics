# 图形符号与统计图形

时间轴上的点表示单次建造事件，横坐标使用线性映射。刻度按十年设置，相邻事件的年差由原始年份相减。

网格比较使用统一宽高的单元。横向格数对应面阔，纵向格数对应进深。网格用于比较间数，数值旁标出的“间”说明使用口径。统一图符单元的重复关系借鉴 ISOTYPE 方法，建筑测绘尺度由具体文献提供。

间数比以面阔间数除进深间数，结果在网格旁直标。实际长宽使用测绘尺寸。归一化高度图使用 1.00 的柱高基准，所有垂直尺寸以相同比例绘制。各构造轮廓的宽度、屋顶曲率及节点形状为示意。

歇山与庑殿的山面示意采用同一视向。歇山高亮上部山花，庑殿高亮整个侧坡。拆层图采用平行斜投影，以标注引线明确四组构造。
