# 视觉风格与设计实验

| 比较项 | 方案 | 采用理由 |
| --- | --- | --- |
| 年份排布 | 等比例轴与均分卡片 | 采用等比例轴，便于直观看出 49 年比 26 年长 |
| 间数图形 | 双向网格与数值表 | 采用网格配数字，两方向可以直接查数 |
| 图面色彩 | 深蓝黑、暖纸色、浅金、朱红 | 深底突出程序绘制的轴测主图，浅底铺开统计、符号及高度比例 |
| 字体 | 中文宋体标题、无衬线注释、等宽编号 | 标题和计数分层，编号在实景、网格与点图间对照 |
| 主视图 | 单体轴测拆层 | 大图从屋面往下引导阅读，照片缩为可核对的实景索引 |
| 案例关联 | 时间轴与网格使用同一顺序 | 读者可以通过建筑名把两层信息对应起来 |

低保真方案见 [版式草图](../../08-%E8%AE%BE%E8%AE%A1%E5%AE%9E%E6%96%BD/01-%E8%8D%89%E5%9B%BE%E4%B8%8E%E4%BD%8E%E4%BF%9D%E7%9C%9F/%E7%89%88%E5%BC%8F%E8%8D%89%E5%9B%BE.png)。正式成图和脚本见 [设计实施](../../08-%E8%AE%BE%E8%AE%A1%E5%AE%9E%E6%96%BD/README.md)。
