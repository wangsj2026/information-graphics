# 视觉编码矩阵

| 数据 | 图形变量 | 编码规则 | 核查方式 |
| --- | --- | --- | --- |
| 公元年份 | 横坐标 | 780–860 年统一按线性尺度定位 | 对照刻度和年份字段 |
| 年份差 | 线段端点及数字 | 连起相邻两节点，数字为晚年减早年 | 49、26，合计 75 年 |
| 面阔间数 | 网格列数 | 一列对应面阔方向的一间 | 数三个网格的列数 |
| 进深间数 | 网格行数 | 一行对应进深方向的一间 | 数三个网格的行数 |
| 间数比 | 直标 | 网格左侧显示比值，标签四舍五入至两位小数 | 逐座计算面阔间数 ÷ 进深间数 |
| 外檐柱头铺作 | 两类符号与数量 | 水平短线表示抄，朱红斜线表示下昂，每类构件每跳一个单位 | 对照 S08，验证三座的出跳数 2、2、4 |
| 纵向高度比例 | 垂直长度与分层填色 | 柱高统一映射为 74 图面像素，铺作高和屋架高用相同比例系数 | 对照 S09，复核 0.38/0.61 及 0.43/1.03 |
| 构造层 | 轴测投影和垂直分隔 | 四层按结构位置排列，标注引线连到相应部位 | 网格宽深来自计数字段，其他外形和层间距为示意 |
| 屋顶形制 | 轴测面和浅金色高亮 | 歇山突出山花，庑殿突出自脊端下至檐口的侧坡 | 对照形制字段、出处与实景 |
| 建造事件 | 文本 | 节点下方直接写建造或重建 | 对照事件列 |
| 县名 | 文本 | 实景标题下显示市、县 | 对照数据表行政地名 |
| 视觉强调 | 颜色 | 朱红用于时间节点、下昂符号与剖面的屋架部分 | 检查去色时仍可凭位置和文字读出数值 |
