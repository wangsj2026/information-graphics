# 03 · 数据搜集

- [公共资料入口](01-%E5%85%AC%E5%85%B1%E6%95%B0%E6%8D%AE%E9%9B%86/README.md) 记录机构公开网页和报告的进入方式。
- [文献来源索引](02-%E6%96%87%E6%9C%AC%E6%96%87%E7%8C%AE/%E6%9D%A5%E6%BA%90%E7%B4%A2%E5%BC%95.csv) 标出来源编号、机构、标题、链接、具体位置和支持的字段。
- [实景照片来源与授权](02-%E6%96%87%E6%9C%AC%E6%96%87%E7%8C%AE/%E7%85%A7%E7%89%87%E6%BA%AF%E6%BA%90.csv) 记录每张照片的原图、作者、授权及图版内的处理方式。
- [自建数据集说明](03-%E8%87%AA%E5%BB%BA%E6%95%B0%E6%8D%AE%E9%9B%86/README.md) 说明如何从文献转录建筑记录。

以公开机构资料的建筑条目为起点，按建筑名和具体殿宇对应资料。转录前核对建筑事件口径，记录公元纪年，并分别读出面阔与进深的间数。

构造补充资料使用 S08 的柱头铺作条目和 S09 的剖面比例表。前者有三座殿宇的可比构造描述，后者只录入南禅寺和佛光寺两座。资料定位及空值原因随表提交。
