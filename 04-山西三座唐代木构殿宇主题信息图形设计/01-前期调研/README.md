# 01 · 前期调研

## 研究问题

三座现存唐代木构殿宇的文献纪年相隔多少年？用统一的间数口径观察，它们的面阔和进深有什么差异？

## 范围与受众

选取山西南禅寺大殿、广仁王庙正殿和佛光寺东大殿三座殿宇，涵盖公元 782–857 年的建造或重建事件。研究单元采用具体殿宇。时间轴与网格的统计范围也限于这三座。面向初次接触古建平面术语的课程读者，采用一张竖版信息图，并配可追溯数据。

## 初步资料

- 核对南禅寺大殿的平梁墨书所对应的重建年代及面阔、进深。 [中国文化研究院 · 中国名刹·山西五台南禅寺](https://chiculture.org.hk/sites/mainsite/files/2019-05/20208_zhongguomingsha_pdf_cn_5.pdf)
- 按文旅部条目核对广仁王庙建造年及正殿面宽、进深。 [中华人民共和国文化和旅游部 · 山西·运城“巧夺天工 古建艺游”](https://zhuanti.mct.gov.cn/xcss2024_xcygj/shanxi/detail/7210.html)
- 通过实地考察报告核对佛光寺东大殿的重建纪年和间数。 [香港古物咨询委员会 · 2005 年山西考察报告](https://www.aab.gov.hk/filemanager/aab/common/122meeting/AAB_43_2005-06_b5.pdf)
- 核对“面阔”和“进深”的建筑释义。 [上海市绿化和市容管理局 · 中国古建筑知识——阔与进深](https://lhsr.sh.gov.cn/jnylwh/20211028/bfe4620f9f9f47fe81df6e65fbc55e85.html)
