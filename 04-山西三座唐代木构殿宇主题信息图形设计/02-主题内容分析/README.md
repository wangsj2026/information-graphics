# 02 · 主题内容分析

## 与大模型协作记录

1. 讨论从山西唐代木构入手，把研究范围缩到三座有明确纪年和间数资料的具体殿宇。
2. 大模型提出用年份排序，并通过平面网格比较面阔和进深。随后逐项核对资料，采用文旅部所载广仁王庙面阔五间。
3. 确定三座研究对象后，从实景进入同一组比较。先看三处事件相隔多久，再比较两个方向的间数和间数比，最后辨认屋顶形制。

## 类型、标签和风格

| 维度 | 本项目选择 | 理由 |
| --- | --- | --- |
| 基础信息逻辑 | 编年型 | 以可计算的公元年份组织建筑事件和阅读顺序 |
| 表现形式 | 时间轴型、比较型 | 线性轴读年差、等距网格读间数、点图读间数比 |
| 视觉风格 | 建筑图谱式平面设计 | 实景用照片，形制用轴测示意，数值用位置和直标 |
| 方法借鉴 | 借鉴 ISOTYPE 的固定单位重复原则 | 同尺度的格子重复表达间数，二维网格同时承载方向 |

样本内可以比较年代、间数和屋顶形制的差异。跨年代的总体演变需要扩充样本和其他建筑变量。

构造图谱版将研究问题扩展到柱头铺作和纵向高度比例。大模型协作阶段梳理拆层轴测与同尺度对照的分工，核查阶段回到三座柱头铺作的出处和剖面比例表。屋面、铺作层、外柱列和间数网格采用程序绘制，保留三张实景作为殿宇索引。
