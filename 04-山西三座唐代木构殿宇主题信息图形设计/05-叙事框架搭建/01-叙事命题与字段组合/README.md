# 叙事命题与字段组合

| 阅读问题 | 使用数据 | 画面输出 |
| --- | --- | --- |
| 三座殿宇的年代怎样排序？ | `building_name`、`year_ce`、`event_type` | 按年份排列的事件点，附殿宇名和事件类型 |
| 相邻年代差多少？ | 排序后相邻记录的 `year_ce` | 831 − 782 = 49 年，857 − 831 = 26 年 |
| 三座殿宇在两个方向各有几间？ | `building_name`、`front_bays`、`depth_bays` | 3 × 3、5 × 3、7 × 4 三张对齐网格 |
| 将面阔与进深相比，哪些殿宇接近？ | `front_bays` ÷ `depth_bays` | 网格旁的比例标签保留两位小数，显示为 1.00、1.67、1.75 |
| 两种屋顶怎样区分？ | `roof_type`、`roof_source_id` | 同观察角度下对照歇山山花和庑殿侧坡 |
| 同样双抄，外檐还有什么差异？ | `bracket_puzuo`、`horizontal_jumps`、`angled_jumps` | 五、五、七铺作及 2、2、4 跳，佛光寺标明两下昂 |
| 柱高统一后，纵向层次有多大差别？ | `bracket_to_column`、`roof_to_column`、`vertical_source_id` | 比例剖面对齐 0.00 和 1.00，比较两座的铺作与屋架，另标资料范围 |
| 样本位于哪些地方？ | `building_name`、`city`、`county` | 每个建筑模块的市、县标签 |

读者先看到 75 年的整体跨度，再从节点间距读到两个不同的间隔，随后用下方网格核对间数。归一到面阔与进深的比值后，广仁王庙正殿与佛光寺东大殿相差约 0.08。
