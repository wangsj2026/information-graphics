# 信息组织与版式结构

1. 主图区做佛光寺东大殿四层轴测，按屋面、外檐铺作、外柱列、间数网格向下读。
2. 实景条带用编号对照三座建筑。下方以线性时间轴和同单位网格比较年份与间数。
3. 三行符号分解柱头铺作出跳。歇山、庑殿的同视向示意承担形制辨认。
4. 两栋样本以柱高 1.00 画纵向比例，标出铺作高和屋架高。
5. 图底列出文献口径和照片授权，出处由来源编号追溯。
