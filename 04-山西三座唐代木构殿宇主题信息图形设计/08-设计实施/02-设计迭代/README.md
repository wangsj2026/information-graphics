# 设计迭代

1. 初稿以标题、时间轴和网格比较三座建筑。实景版加入屋顶形制和间数比。
2. 构造图谱版把佛光寺东大殿的拆层轴测放至主区，压缩照片篇幅，增加柱头铺作的出跳对照以及两座的纵向高度比。
3. 用相同图面单位比较间数与高度比。静态导出默认完全拆层，交互图版可使用滑杆调节。

| 校验项 | 结果 |
| --- | --- |
| 样本顺序 | SX01 南禅寺大殿、SX02 广仁王庙正殿、SX03 佛光寺东大殿 |
| 公元纪年与轴位置 | 782、831、857 年，分别为 2.50%、63.75%、96.25% |
| 相邻纪年差 | 49 年、26 年 |
| 面阔 × 进深 | 3 × 3、5 × 3、7 × 4 间 |
| 出跳数 | 2、2、4，佛光寺为双抄双下昂 |
| 铺作高/柱高 | 南禅寺 0.38，佛光寺 0.43 |
| 屋架高/柱高 | 南禅寺 0.61，佛光寺 1.03 |
| 高度比空值 | 广仁王庙未列入 S09 表二 |
