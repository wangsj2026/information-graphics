# 03 · 统计图形分析

本目录用于拆解案例里用到的统计图形，包括所需数据列、数据清洗与汇总、视觉编码和适用条件。后续可从 `02` 的案例原图入手，为每种图形记录选用依据和计算方法。

按老师当前示例，本目录先建立说明页，具体图表分析随课堂安排补充。 [老师的目录说明](https://github.com/fengbaifan/Infographic-Style-Repository/tree/main/03-%E7%BB%9F%E8%AE%A1%E5%9B%BE%E5%BD%A2%E5%88%86%E6%9E%90)
