# 04 · 统计图形分析

| 图形 | 最小字段 | 编码及计算 | 易错点 |
| --- | --- | --- | --- |
| 单指标折线 | 时间、指标值、实体 | 时间排序，纵轴按同口径数值定位。缺失时间保留断点。 | 缺测读成零；单位变化前后直接对接。 |
| 数量流线 | 出发位置、到达位置、方向、数量 | 宽度与数量按明示比例对应。米纳尔案例以每万人对应 1 mm。 | 用流线面积代替宽度比较；把分流和减少混为一谈。 |
| 双变量分级设色 | 地理单元、变量 A、变量 B | 两列数值各自分级，再查二维颜色矩阵。 | 图例只写颜色，未标两个方向和分级。 |
