# 文字型与列表型信息图形

Informational / List Infographics

## 概念与判断方法

以短文本或条目承载内容，通过标题、分区、列表标识和插画提高扫描效率。适合汇集建议、说明、清单和可独立执行的行动。当上一项是下一项的必要条件时，应考虑用步骤或流程关系提示先后。
