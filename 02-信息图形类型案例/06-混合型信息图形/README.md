# 混合型信息图形

Mixed Charts

## 概念与判断方法

混合型信息图形把多种图表或视觉语言组织到同一个阅读任务里。地图、流线、折线、矩阵或图像符号可以各自处理一种关系，读者依靠共享的地点、类别、时间或标注建立联系。设计前先找能跨图对齐的字段，再确定颜色、尺度和图例是否需要各自解释。

## 对照观察

米纳尔图借路线位置对齐兵力与温度。爱沙尼亚选举图使用政党配色连接地图、席位栏和得票率条形，另用环图呈现独立的全国投票率。两图分别使用位置与类别协调多张图表。

可继续对照 ISOTYPE《社会与经济》第 46 图，观察图符和地图如何共享地理框架。一枚轮胎图符代表 25,000 吨，空心与实心标示不同的贸易状态。 [图版与图例说明](https://isotyperevisited.org/2012/08/society-and-economy.php)
