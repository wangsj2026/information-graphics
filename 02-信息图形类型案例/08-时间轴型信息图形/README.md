# 时间轴型信息图形

Timeline Infographics

## 概念与判断方法

用一条或多条时间路线组织时间节点、区间及关联标注。时间轴是版面形式，能承载编年数据，也能同时承载项目、组织或地理主题。等距刻度可以比较真实间隔。里程碑按内容宽度排布时，阐释依据是标注的时间值。
