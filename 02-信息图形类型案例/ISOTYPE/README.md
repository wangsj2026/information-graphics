# ISOTYPE

ISOTYPE 源于维也纳图形统计方法。这个标签用于标记通过标准化象形符号呈现社会或经济数据的设计，适用于比较、地图和其他信息图形。

## 编码规则

| 数据字段 | 图面表达 |
| --- | --- |
| 类别 | 选择相应的象形符号 |
| 数值 | 使用同样大小的图符，按固定单位重复排列 |
| 状态 | 在图符上叠加颜色、空心或实心，并在图例中解释 |
| 地点 | 按地图地点或区域放置图符组 |

先统一单位，再用“数值 ÷ 每个图符代表的量”计算符号数量。遇到余数，可以在图例说明所用的半符号或舍入规则，并保留精确数值供核对。

## 案例

**《社会与经济》第 46 图《世界橡胶经济》** 每个轮胎符号代表 25,000 吨。绿色实心轮胎表示生产并出口，绿色空心轮胎表示进口，橙色实心轮胎表示本地生产并使用的再生橡胶。作为换算示例，如果一处有 3 个同类图符，对应 75,000 吨。 [图版及馆藏说明](https://isotyperevisited.org/2012/08/society-and-economy.php)
