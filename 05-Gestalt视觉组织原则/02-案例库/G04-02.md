# G04-02 · Johansson 点光行走

类型为实验或理论演示。关联 [ 共同命运律 ](../01-规则库/G04-共同命运律.md)。

## 观察证据

肢体关节的点随身体协调运动时可读出行人。本例同时涉及生物运动整合，运动线索不限于共同位移。

## 设计迁移

在动态图中用一致的移动方向提示同一群体，并检查相邻无关对象的运动是否造成误判。

可把文中的构图线索作为下一轮草稿的对照变量。观察这里只用于分析该图面或研究样例。
