# G06-02 · 伦敦地铁线路图

类型为既有设计或视觉材料。关联 [ 连接律 ](../01-规则库/G06-连接律.md)。

## 观察证据

车站被同一线路连接后读作路线节点；换乘符号区分可换乘连接和仅画面相交的线段。

## 设计迁移

让引线落在准确端点，用连续线或节点关系表达明确的连接。交叉处标出是否相交。

可把文中的构图线索作为下一轮草稿的对照变量。观察这里只用于分析该图面或研究样例。
