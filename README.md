# 信息图形设计 · 数据逻辑与案例库

阅读目标是从现成信息图里辨认数据怎样组织、图形怎样编码，以及版面怎样引导阅读。

## 图例、尺度与数据核对

16 个案例均有数据与编码检验。数值案例记录图上单位、尺度和换算过程。类别案例记录索引、分级或符号规则。

## 分类原则

先辨认读者依靠什么关系理解数据，再辨认图形采用了什么版面形式。编年型描述时间怎样组织记录，时间轴型描述节点、刻度和阅读路径怎样显示。某图可以同时具备两类属性，本库按它最适合讲解的特征归档。

## 添加案例

在对应分类中新建案例 Markdown，将图放入该分类的 images 文件夹，注明作者和出处，再补上分类页链接。复读已有说明时，重点检查新案例是否补充了数据结构、编码或叙事的规律。

课程分类依据为冯白帆《信息图形设计导论》第 3 章，见课件 PDF 第 47–84 页。各案例出处收录在对应分析页。
