# 数据字典与溯源

| 字段 | 类型 | 口径 |
| --- | --- | --- |
| `building_id` | 文本 | 殿宇唯一标识，供表格、时间轴与网格对应 |
| `building_name` | 文本 | 具体殿宇的名称 |
| `city` | 文本 | 现行政所在地级市 |
| `county` | 文本 | 现行政所在县 |
| `year_ce` | 整数 | 文献记载的建造或重建公元年份 |
| `event_type` | 类别 | 建造、重建 |
| `front_bays` | 整数 | 面阔方向的间数 |
| `depth_bays` | 整数 | 进深方向的间数 |
| `source_id` | 文本 | 纪年与间数资料的编号 |
| `roof_type` | 类别 | 单檐歇山、单檐庑殿 |
| `roof_source_id` | 文本 | 屋顶形制资料的编号 |
| `short_name` | 文本 | 图面窄栏用的简称 |
| `bracket_puzuo` | 整数 | 文献记载的柱头铺作等级数 |
| `horizontal_jumps` | 整数 | 抄（杪）的向外出跳数 |
| `angled_jumps` | 整数 | 下昂的向外出跳数 |
| `bracket_source_id` | 文本 | 柱头铺作与出跳构成的来源编号 |
| `bracket_to_column` | 小数或空值 | 铺作高 ÷ 柱高，按 S09 表二转录 |
| `roof_to_column` | 小数或空值 | 屋架高 ÷ 柱高，按 S09 表二转录 |
| `vertical_source_id` | 文本或空值 | 高度比较的来源编号，有资料的两座为 S09 |

## 逐座核对

| 殿宇编号 | 建筑数据来源 | 定位 |
| --- | --- | --- |
| SX01 | S01 | PDF 第 69 页的南禅寺大殿段落，关联大殿重建年代和两个方向的间数 |
| SX02 | S02 | 芮城县广仁王庙条目，关联 831 年建造、面阔五间和进深三间 |
| SX03 | S03 | PDF 第 33 页佛光寺东大殿段落，关联 857 年重建、面阔七间和进深四间 |

三座殿宇的屋顶形制依次定位到 S01、S06、S03。地名使用当前市县级标注。对重建殿宇采用本次比较所选的殿宇纪年。网格以间数绘制，图面格子的宽高属于统一画布单位。术语与交叉核对来源见 [来源索引](../../03-%E6%95%B0%E6%8D%AE%E6%90%9C%E9%9B%86/02-%E6%96%87%E6%9C%AC%E6%96%87%E7%8C%AE/%E6%9D%A5%E6%BA%90%E7%B4%A2%E5%BC%95.csv)。

S08 对比三座殿宇的柱头铺作。S09 以明间檐柱为基准，表二的柱高含普拍枋高和柱础高，铺作高度由栌斗底至橑檐枋下皮，屋架高度由橑檐枋下皮至脊槫上皮。广仁王庙未列入该表，保留空值。
