# 设计迭代

1. 初稿以标题、时间轴和网格比较三座建筑。实景版加入屋顶形制和间数比。
2. 构造图谱版把佛光寺东大殿的拆层轴测放至主区，压缩照片篇幅，增加柱头铺作的出跳对照以及两座的纵向高度比。
3. 朱砂展板沿用确认的概念稿构图。三座殿宇分别生成透明插画，年表与标注沿建筑间的留白排布，下方设屋顶、斗栱、铺作和开间图带。底部补充两座屋架高／柱高比值相差 0.42 的读数。
4. 辅助交互图版可用滑杆调节拆层距离。[插画生成说明](%E6%8F%92%E7%94%BB%E4%B8%8E%E6%9E%84%E5%9B%BE.md)
