# 风格分析与克隆系统

## 启动

把本文件和参考图拖入图像模型可读的对话，发送「启动风格分析和克隆系统」，附新主题、受众与用途。仓库使用者可以直接读本文件和风格档案。

## 分析与生成

1. 对照参考记录风格本体、色彩、光线、构图、尺度、绘画语言、边缘、完成度、信息密度、材质、主体、视觉锚点与张力。对无关字段注明不适用。
2. 给出图上可证的特征，把风格固定项、项目保留项和新主题变量列清。允许因新主题重排内容层级，保证事实、数据、单位和标签一致。
3. 从同一结构化档案派生中文 JSON、英文 JSON、中文简易提示词、自然语言提示词。核对两种语言的颜色、数量、文字和结构约束后再生成。
4. 固定风格约束并换一个主题出图。逐一记录风格、内容、可读性、技术交付和可移植性。遇到偏差只先改一项再复核。

## 调用格式

```text
启动风格分析和克隆系统
参考图或已保存的风格档案：
新主题与任务目的：
优先保留的规则：
允许替换的变量：
必须准确的文案、单位和数据：
输出：四版提示词、迁移测试图、检查记录
```
